# Agent entry point

Read [CLAUDE.md](CLAUDE.md) and [PROJECT_STATUS.md](PROJECT_STATUS.md) before project work.
Verify the live Git/GitHub state; a saved baseline SHA is not the current HEAD.

[ROADMAP.md](ROADMAP.md) remains the master scope. Read its relevant rows,
the applicable decisions in [DECISIONS.md](DECISIONS.md), and the matching
project skill under `.claude/skills/` before changing that area.
[REVIEW_INTAKE.md](REVIEW_INTAKE.md) records the disposition and acceptance
criteria of the October 3 review suggestions; consult the relevant entry.

This file is a bootstrap pointer, not a second rulebook. The integration owner
maintains the operational handoff; independent reviewers return evidence.
